### Full release notes (wiki)
<!-- rn:full:start -->
**LinqToDB — Fixed**
- Two queries whose expression trees differed only in which lambda a same-named parameter belonged to — e.g. an inner `p` that refers to the outer `p` in one query and to itself in the other — could share one query-cache entry, so the second query silently ran the first one's SQL. C#-compiled lambdas can't produce this; it affected expression trees built or rewritten in code (dynamic predicate builders, expression rewriters).
