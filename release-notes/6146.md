### Full release notes (wiki)
<!-- rn:full:start -->
**Provider bullets**
- **SQLite** — an arithmetic operand of a string concatenation is now parenthesized; SQLite binds `||` tighter than arithmetic, so the operand was evaluated against its neighbour and gave a wrong result:

  ```csharp
  db.GetTable<T>().Select(t => string.Join(",", t.Value + 1, t.Value))
  // Value = 10: returned "11" instead of "11,10"
  ```

  Thanks to [Lay](https://github.com/Lay-quq)
- **Firebird** — an arithmetic operand of a string concatenation is now parenthesized; Firebird binds `||` tighter than every arithmetic operator, unary minus included, so the operand was evaluated against its neighbour. Thanks to [Lay](https://github.com/Lay-quq)
