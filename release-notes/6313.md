### Full release notes (wiki)
<!-- rn:full:start -->
**Sybase ASE — Fixed**
- An explicitly requested provider — `SybaseTools.GetDataProvider(SybaseProvider.…)`, `SybaseTools.CreateDataConnection(…, provider)`, `UseAse(…, provider)` — was ignored and the provider was auto-detected instead, so e.g. `SybaseProvider.Unmanaged` silently returned the managed provider when the native client was not installed. The requested provider is now used; `SybaseProvider.Unmanaged` without `Sybase.AdoNet45.AseClient` fails with an error instead of switching providers.
