### Full release notes (wiki)
<!-- rn:full:start -->
**LinqToDB — Added**
- .NET 11 support: packages now ship `net462`, `netstandard2.0`, `net10.0` and `net11.0` builds. The `net8.0` and `net9.0` builds are discontinued; applications on .NET 8 or .NET 9 use the `netstandard2.0` build.
- On `net462` and `netstandard2.0`, the minimum versions of `Microsoft.Bcl.AsyncInterfaces`, `Microsoft.Extensions.*`, `System.Configuration.ConfigurationManager` and `System.Net.Http.Json` are bumped from 8.0.0 to 10.0.0, the lowest supported .NET version.
- `linq2db.cli`, `linq2db.Remote.HttpClient.Server` and the LINQPad 7+ driver now run on .NET 10 or later; `linq2db.Analyzers` needs Roslyn 5.0 (.NET SDK 10.0.100 / Visual Studio 2026).

**LinqToDB for EntityFramework — Added**
- New `linq2db.EntityFrameworkCore` 11.x package for EF Core 11. Packages for EF Core 8 and EF Core 9 are discontinued; the EF Core 3.1 and EF Core 10 lines continue.
<!-- rn:full:end -->
