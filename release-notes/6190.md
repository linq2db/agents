**LinqToDB — Fixed**
- A window-function value read after a `GroupJoin` is now computed where it is defined. Filtering on it failed, and after a join that multiplies rows it numbered the joined rows instead of the original ones:

  ```csharp
  var ranked = db.Child.Select(c => new
  {
      c.ChildID,
      c.ParentID,
      Rank = Sql.Window.RowNumber(w => w.PartitionBy(c.ParentID).OrderByDesc(c.ChildID)),
  });

  from r in ranked
  join p in db.Parent on r.ParentID equals p.ParentID into pj
  from p in pj.DefaultIfEmpty()
  where r.Rank <= 1
  select r.ChildID
  // LinqToDBException: … Window functions cannot be used in search condition.
  ```
