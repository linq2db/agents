- **Firebird** — a single-quote `char` value written as a literal no longer produces an unterminated string and invalid SQL:

  ```csharp
  db.GetTable<T>().Where(x => x.Ch == '\'')
  // generated "x"."Ch" = ''' — now ''''
  ```
