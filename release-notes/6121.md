**LinqToDB — Fixed**
- Negating a nullable comparison that was projected as a boolean value no longer drops the rows where the compared value is `NULL`:

  ```csharp
  db.Parent
      .Select(p => new { IsOne = p.Value1 == 1, p.ParentID })
      .Where(x => x.IsOne == false)
  // rows with Value1 = NULL were missing; they are now returned, as in LINQ to Objects
  ```

  The same applied to `!= true` on every database, and to `!x.IsOne` on databases without a boolean type (SQL Server, Oracle, Sybase). Thanks to [Ivan Demchuk](https://github.com/Demivan)
