### Full release notes (wiki)
<!-- rn:full:start -->
**Access — Added**
- The `Access.LibRed` provider uses LibRed's extended SQL dialect, so many queries that classic Access cannot run, or that linq2db had to emulate, translate directly: window functions (frames, `FILTER`, `IGNORE NULLS`, statistical aggregates), `Skip`/`Take` paging including inside subqueries, `CROSS` / `OUTER APPLY`, `Intersect` / `Except`, `CASE` expressions, `IS [NOT] DISTINCT FROM`, `Distinct` aggregates such as `Count(x => x.Distinct())`, `string.Join` / `string.Concat` aggregation, `TakeHints` (`WITH TIES`, `PERCENT`), millisecond date parts and `DateTime.UtcNow`. CTEs, `MERGE` and output clauses remain unavailable.

**Access — Fixed**
- C# `^` (XOR) was sent as Access `^`, which is exponentiation, and returned wrong results; it is now translated to `BXOR`.
- `%` (`MOD`), `Math.Pow` / `Sql.Power` and `~x` lost their grouping inside larger expressions — e.g. `(a + b) % c` or a negated power — and could compute wrong values.
<!-- rn:full:end -->
