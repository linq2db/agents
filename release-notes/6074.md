### Full release notes (wiki)
<!-- rn:full:start -->
**LinqToDB — Fixed**
- C# 14 compiles `ids.Contains(x.Id)` over an array to a span-based `MemoryExtensions.Contains` call. In the `netstandard2.0` build — used by any application whose target framework has no dedicated linq2db build, and by applications that reference linq2db through a `netstandard2.0` library — such queries failed with "could not be converted to SQL"; they now translate to `IN`. Inline-array `Min()` / `Max()` that bind the same way (`new[] { a, b }.Max()`) are translated as well, instead of failing or being evaluated on the client.
<!-- rn:full:end -->
