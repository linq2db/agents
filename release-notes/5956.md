### Full release notes (wiki)
<!-- rn:full:start -->
**Access — Added**
- New `Access.LibRed` provider (`ProviderName.AccessLibRed`, `AccessProvider.LibRed`) on top of the fully managed [LibRed.Ado](https://www.nuget.org/packages/LibRed.Ado) driver (currently a beta). It reads and writes `.mdb` and `.accdb` files on Windows, Linux and macOS without the Access Database Engine, OLE DB or ODBC, and requires .NET 10 or later. Select it with `UseAccess(connectionString, AccessProvider.LibRed)` or the `Access.LibRed` provider name; a plain `Data Source=<file>` connection string still resolves to the classic providers.
- `AccessTools.CreateDatabase` and `AccessTools.DropDatabase` overloads that take an `AccessProvider`, so database files can be created and dropped through LibRed.
- LibRed keeps no `.ldb` / `.laccdb` lock file, so don't open the same database file from several processes at once.

**LinqToDB CLI — Added**
- `AccessLibRed` scaffold provider: scaffold Access databases on any OS with no driver installed (`LibRed.Ado` ships with the tool).

**LinqToDB LINQPad Driver — Added**
- Access connections get a provider selector (OLE DB, ODBC, LibRed). On non-Windows hosts LibRed is the default and the only choice.
