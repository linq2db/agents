**LinqToDB — Fixed**
- A `Union` or `Intersect` where one side projects an optional object — from a `DefaultIfEmpty()` join, a nullable association or a `FirstOrDefault()` subquery — and the other side projects `null` in its place no longer throws `Could not decide which construction type to use`, in either order:

  ```csharp
  var withChild = from p in db.Parent
                  from c in db.Child.Where(c => c.ParentID == p.ParentID).DefaultIfEmpty()
                  select new { p.ParentID, Child = c };
  var noChild   = db.Parent.Select(p => new { p.ParentID, Child = (Child?)null });

  withChild.Union(noChild)
  ```

  Thanks to [Ivan Demchuk](https://github.com/Demivan)
