### Full release notes (wiki)
<!-- rn:full:start -->
**Access — Fixed**
- Ordering by a Yes/No column or a boolean expression now puts `false` before `true`, as .NET and every other database do. Access stores `True` as `-1`, so such keys sorted `true` first:

  ```csharp
  db.Person.OrderBy(p => p.ID > 1)
  // Access returned the ID > 1 rows first
  ```

  This also applies to window-function `ORDER BY`. A nullable key still sorts `NULL` first, except under `DISTINCT`, where it now sorts last.
