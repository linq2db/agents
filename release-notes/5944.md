### Full release notes (wiki)

**LinqToDB — Improved**
- The `net11.0` build of `linq2db` and its satellite packages is compiled with .NET 11 runtime async: `async` methods are suspended and resumed by the runtime instead of compiler-generated state machines.
- `linq2db`, `linq2db.Remote.Grpc`, `linq2db.Remote.HttpClient.Client` and `linq2db.Remote.SignalR.Client` also ship a `runtimes/browser-wasm` `net11.0` build without runtime async. NuGet picks it automatically for Blazor WebAssembly apps, because the Mono WebAssembly runtime can't run runtime-async code.
<!-- rn:full:end -->
