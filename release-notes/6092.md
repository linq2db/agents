**Provider bullets**
- **PostgreSQL** — with Npgsql 10, reading a `date`, `time` or `daterange` column into a `DateTime`, `TimeSpan` or `NpgsqlRange<DateTime>` member no longer fails with `LinqToDBConvertException` (`Cannot convert value '12/12/2012: System.DateOnly' to type 'System.DateTime'`) when an application on a modern runtime loads LinqToDB's netstandard2.0 build, for example through a netstandard2.0 library. A `date` read into a `string` there now returns `2012-12-12`, as on .NET 8 and later.
