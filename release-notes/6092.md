### Full release notes (wiki)
<!-- rn:full:start -->
**PostgreSQL — Fixed**
- In the `netstandard2.0` build — used by any application whose target framework has no dedicated linq2db build, and by applications that reference linq2db through a `netstandard2.0` library — reading an Npgsql 10 `date`, `time` or `daterange` column into a `DateTime`, `TimeSpan` or `NpgsqlRange<DateTime>` member failed with `LinqToDBConvertException` (`Cannot convert value '12/12/2012: System.DateOnly' to type 'System.DateTime'`); `date` and `time` values now read into `DateTime`, and a `date` read into a `string` returns `2012-12-12`, as in the `net10.0` / `net11.0` builds.

**LinqToDB — Fixed**
- In the `netstandard2.0` build, `DateOnly` values now convert to `DateTime` and `string` again (e.g. `ConvertTo<DateTime>.From(dateOnly)`).
