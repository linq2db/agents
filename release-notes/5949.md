**PostgreSQL — Fixed**
- Filtered aggregates no longer emit a `FILTER (WHERE …)` clause on PostgreSQL 9.2 and 9.3, where it is a syntax error; the equivalent `CASE WHEN` form is used there instead:

  ```csharp
  db.Child.GroupBy(c => c.ParentID).Select(g => g.Where(c => c.ChildID > 20).Count())
  // PostgreSQL 9.2/9.3: 42601: syntax error at or near "("
  ```

  PostgreSQL 9.5 and later still get `FILTER`. A 9.4 server, and a connection whose server version is not detected, use the `CASE WHEN` form too; the results are the same.
