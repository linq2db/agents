### Full release notes (wiki)

**LinqToDB — Fixed**
- A filtered `ThenLoad` on a query whose source is a `SelectMany` or a join now binds to the entity it loads from. When the query's selected entity had a member with the same name, the filter was bound to that member instead: it failed with `LinqToDBException: Invalid filter function usage.`, or, when the two members also had the same type, loaded the wrong data without an error:

  ```csharp
  (from o in db.GetTable<Org>()
   from a in db.GetTable<OrgSystem>().Where(a => a.OrgId == o.Id)
   join s in db.GetTable<SystemEntity>() on a.SystemId equals s.Id
   select s)
  .LoadWith(s => s.Stages).ThenLoad(st => st.Product)
  .ThenLoad(p => p.Organisations, q => q.Where(x => ids.Contains(x.OrgId)))
  // SystemEntity has an Organisations member too
  ```

  Versions up to 5.4.1.9 were not affected.
