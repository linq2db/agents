**LinqToDB — Fixed**
- `Sum()` over a projection that calls a method, inside a correlated subquery, no longer fails to translate; this broke in 6.2.0:

  ```csharp
  // Row has an int ParentId and a decimal Value
  db.Parent.Select(p => db.GetTable<Row>()
      .Where(r => r.ParentId == p.ParentID)
      .Select(r => Math.Max(0m, r.Value))
      .Sum())
  // ArgumentException: Expression of type 'IQueryable<Row>' cannot be used for parameter of type 'IQueryable<Decimal>' …
  ```

  Thanks to [Shane Krueger](https://github.com/Shane32)
