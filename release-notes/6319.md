### Full release notes (wiki)
<!-- rn:full:start -->
**LinqToDB Remote Context — Fixed**
- Since 6.5.0, `SignalRDataContext(HubConnection, …)` disposed the caller's `HubConnection` together with the context, so another context sharing that connection failed with `ObjectDisposedException`. The caller owns the connection again, as before 6.5.0.

**LinqToDB Remote Context — Added**
- New `SignalRDataContext(HubConnection hubConnection, bool disposeHubConnection, Func<DataOptions, DataOptions>? optionBuilder = null)` constructor; pass `disposeHubConnection: true` to have the context dispose the connection.
<!-- rn:full:end -->

### GitHub release highlight (brief)
<!-- rn:brief:start -->
SignalR remote context no longer disposes a caller-supplied `HubConnection` (6.5.0 regression).
