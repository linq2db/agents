### Full release notes (wiki)
<!-- rn:full:start -->
**DuckDB — Fixed**
- `TimeOnly` literals lost their milliseconds (`23:59:59.999999` was written as `…59.000999`).
- `TimeSpan` interval literals: a negative value under one day lost its sign, a negative value with days negated only the days (`-30.12:30:45` became `-30 days 12:30:45`), and very large values could round up by a day.
- `DuckDBInterval` literals dropped negative months and days, and negative microseconds made DuckDB reject the query.
- Provider-specific `BulkCopy` now converts `TimeOnly` values written into a `TIMETZ` column.

**LinqToDB CLI — Fixed**
- DuckDB `DECIMAL` values in query output were printed as the type name `DuckDBDecimal` instead of the number.
