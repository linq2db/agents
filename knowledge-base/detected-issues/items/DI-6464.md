# DI-6464 — Informix truncate reset omits TableOptions that Access, DB2 and SqlCe pass

**Severity**: low  **Category**: code-smell  **Status**: open

## Location
- `Source/LinqToDB/Internal/DataProvider/Informix/InformixDmlService.cs:29` — table name expression built without table.TableOptions
- `Source/LinqToDB/Internal/DataProvider/Access/AccessDmlService.cs:27`, `DB2/DB2DmlService.cs:40`, `SqlCe/SqlCeDmlService.cs:27` — pass table.TableOptions

## Pattern matched
Cross-provider inconsistency inside the duplicated reset blocks (see DI-6460).

## Why it matters
If TableOptions affect how the table is named, Informix may reference a different object in the ALTER than in the TRUNCATE.

## Suggested fix
Pass table.TableOptions as the siblings do, or comment why Informix names are unaffected. Best done with the DI-6460 consolidation.

None found.
