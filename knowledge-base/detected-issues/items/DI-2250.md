# DI-2250 — Notification.Log swallows all exceptions with empty catch blocks

**Severity**: med  **Category**: code-smell  **Status**: open

## Location
- `Source/LinqToDB.LINQPad/UI/Notification.cs:146` — empty catch in Log(Exception, string)
- `Source/LinqToDB.LINQPad/UI/Notification.cs:157` — empty catch in Log(string, string)

## Pattern matched
Catch block with empty body.

## Why it matters
A comment at line 139 says logging must never replace the reported error, so the swallow is deliberate. A logging failure is still invisible, and the bare `catch` also hides fatal exceptions.

## Suggested fix
Catch `Exception` explicitly, and add a short comment or a Debug.WriteLine in the body.
