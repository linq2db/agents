# SQL-AST -- GitHub themes

## Open themes
- **Type information lost between translation and SQL emission** -- Expression type metadata is not carried on SQL nodes, so emission recovers it from column descriptors, schema defaults or a provider default, and can get it wrong. Open: #5758 (carry type mapping on SQL expressions instead of recovering it from ColumnDescriptor), #6044 (attribute-built SQL reports the mapping schema's default type, not the value's), #6056 (a typed SqlBinaryExpression loses its DbDataType when a visitor rebuilds it), #6055 (remote context drops the DbDataType of binary and unary nodes; fix in draft PR #6057), #6079 (inline IN list values are typed through SUM and type-changing casts), #5759 (TimeSpan members and comparisons on native interval columns), #5961 (three ClickHouse date translations declare a type that contradicts the SQL they emit), #6228 (Sum() of a value-converted column compared with a parameter does not convert the parameter), #6213 (Sql.Property<T> with T different from the member type fails translation; PR #6268 converts it). Closed since the last pass: #5960, #6064 (see Resolved).
- **Literals and casts rendered at the wrong type** -- Date/time, decimal, enum and cast text is written at a type or precision that differs from the operand, so comparisons and reads change without an error. Open: #5997 (date/time literal compared with a coarser column loses its sub-second part), #6117 (ClickHouse TimeSpan constant written as whole seconds), #5973 (ulong.MaxValue literal fails on SQLite, SQL Server, Sybase and Firebird; inlined values), #5977 (DuckDB CURRENT_TIMESTAMP in a CASE shifts a TIMESTAMP parameter), #6078 (SQL Server datetime literal beside MAX or COALESCE of a datetime column is written as datetime2 and misses a read-back value), #6081 (SQLite and ClickHouse: a date column IN a list of datetime columns misses a match that == finds), #6049 (MySQL CAST to a date/time type drops fractional seconds), #6071 (text to date/time casts wrong on SQLite and Informix, no rows on YDB), #6062 (SqlCe compares a decimal literal at the other operand's scale), #6019 (DB2 recursive CTE anchor double-casts a DateTime literal; result unaffected, SQL longer than needed), #6298 (comparisons over a cast to an unregistered enum return wrong rows), #6277 (comparisons over a projected enum cast; PR open).
- **Null semantics of emitted predicates and casts** -- A predicate or cast that is UNKNOWN or folded away in SQL evaluates differently from the C# expression over NULL. Open: #6065 (DB2: a nullable equality ORed with another condition evaluates to UNKNOWN when compared as a value), #6066 (nullable inline-array Contains converted to a string returns NULL where C# returns "False"), #6070 (a narrowing numeric conversion followed by a widening back is dropped before SQL is built), #6209 (ORDER BY a comparison over a nullable operand sorts unknown rows apart from false), #6256 (CompareNulls.LikeSql: a comparison with a NULL parameter folds to FALSE), #6244 (lifted bool? AND and OR over a comparison render invalid SQL on some providers), #6165 (grouped or correlated Distinct().Count() drops NULL and is written as COUNT(DISTINCT x)), #6262 (YDB: Sql.Substring and Sql.Left with a NULL length return the rest of the string), #6202 (YDB: a cached direct query keeps the NULL check of a Binary comparison).
- **Calculations over missed LEFT JOIN rows** -- A calculation over a non-matching LEFT JOIN row is evaluated over SQL NULL, and the server rejects it or answers differently from C#. Open: #6046 (eager-load and CTE projections still calculate over NULL with PreferClientCalculation off), #6087 (math functions over a missed row throw "Nullable object must have a value" with the option on), #6088 (Sybase: DateTime and Sql.MakeDateTime over NULL parts raise a conversion error), #6089 (ClickHouse: decimal division by a missed row raises "Decimal convert overflow"), #5929 (PreferClientCalculation: a missed LeftJoin computes on default(T) instead of NULL), #5928 (a declined instance-method translation gets a null receiver). Projection calculations are fixed by #5983 (see resolved).
- **Set operations and CTE column projection** -- Projection over set-operation members and CTE columns produces invalid or bloated SQL, and null branches read back wrong rows. Open: #5822 (recursive CTE with a UNION body emits invalid SQL when the projection computes over CTE columns), #5881 (chain of 3+ set operations pads members apart when a branch projects a derived type), #6094 (Union or Concat of a lifted struct with a (T?)null branch builds no marker column for the null branch, and reading throws NullReferenceException), #6050 (Sybase: UNION of a date column with a datetime value truncates the datetime branch to a date), #6183 (Union, Intersect or Except return wrong rows for a query-written null test against an optional object), #6187 (reading a member of an optional object after Union or Intersect with a null branch). Resolved siblings: #5617 (ordering of columns inside UnionAll), #5457 (6.x removes CTE columns).
- **Subquery shape: apply joins, TOP and aggregate placement** -- Correlated subqueries, derived tables and aggregates are emitted in a shape the server rejects or evaluates differently. Open: #6032 (Access: uncorrelated TOP 1 ORDER BY column subquery with a nested correlated subquery returns per-row wrong values), #6034 (apply joins over set operations are never decorrelated, so they always need LATERAL / APPLY), #6047 (Access: GroupBy(...).Select(aggregate).Contains puts the aggregate in WHERE), #6234 (correlated GroupBy keyed on an outer-row member emits the outer column in GROUP BY). Open draft PR #5900 (Sybase: TOP of a First() applied to the whole eager-load join) covers a related derived-table TOP case.
- **Identifier quoting and parameter naming** -- Names that reach generated SQL text, identifiers and parameters are not reliably quoted, escaped or kept unique. Open: #6022 (identifier passthroughs on seven providers and unescaped embedded quotes on nine; an injection vector when names come from runtime strings), #6040 (an explicitly named DataParameter is renamed when a generated parameter claims its name first), #5772 (open PR: respect per-provider identifier length limits and keep Unicode aliases). Resolved: #6023 (Sybase empty field name) fixed by #6039.
- **Constant and redundant nodes reach the server** -- Expressions that should fold or reduce before emission are emitted as written, and the optimizer pass meant to catch them is costly. Open: #5851 (constant WITHIN GROUP / KEEP sort key reaches the server verbatim), #5963 (redundant non-mandatory SqlCastExpression built by a provider is not reduced), #5911 (whole-tree expression optimizer runs five times per build), #6279 (translation time and memory grow exponentially with a left-deep chain of + in a query), #5738 (audit and optimize visitor-based tree traversals in query compilation). Resolved sibling: #5806 (constant window ORDER BY emits a bare integer index).
- **String width and concatenation typing** -- Concatenation and string functions get a parameter, column or length type that cuts or rejects the text. Open: #6212 (SQL Server: string concatenation with a parameter is cut at 4000 characters), #6236 (SQL Server: Replace over a VarChar(n <= 4000) value with a Unicode argument is cut), #6238 (SQL Server: PadRight and Sql.PadLeft over 4000 characters are cut at 4000), #6227 (SQL Server: string.Length of a VarChar value longer than 4000 characters), #6193 (Access: concatenating a column with a non-null string parameter overflows), #6195 (DB2: the same concatenation shape fails with CLI0109E), #6200 (PostgreSQL: string.Join over object items, CONCAT_WS typed as its first item). Resolved: #6186 and #6194 (Unicode arguments beside a VarChar column).
- **Rounding and math functions at the wrong precision** -- Math functions over decimal or double operands are emitted at a precision or return type the engine does not match. Open: #6100 (DuckDB: Math.Round or Sql.Round with a non-constant precision on a decimal fails), #6275 (DuckDB: Math.Round with a precision on a large decimal overflows or loses digits), #6263 (DB2: Math.Round(double, digits) to-even differs from .NET), #6041 (YDB: Math.Floor, Ceiling and Truncate over a decimal lose precision through Double), #6072 (integer Sql.Degrees overloads keep the fraction where DEGREES returns a float). Resolved: #5943 (YDB ROUND widening, merged 2026-10-22).
- **Date/time differences and offsets** -- Differences and sub-day functions over date/time values are measured on the local reading or fail on narrower operand types. Open: #5776 (Contains over a computed duration difference does not reconcile units), #5796 (set operation over a computed difference and a declared duration), #5797 (DateTimeOffset difference measured on the local reading, not the instant), #5989 (Access: a projected difference of two local DateTime values is read back as TIME), #5965 (sub-day date functions over date-only, DATE or low-precision operands fail on SQL Server, Firebird, Oracle and DuckDB), #5892 and #5913 (DateTimeOffset, both draft PRs).
- **LEFT JOIN ON predicate placement** -- A predicate that reads only the outer side of a LEFT JOIN is moved from ON into WHERE or applied as a filter, dropping outer rows. Open: #6215 (Access: LEFT JOIN ON predicate reading only the outer side is applied as a filter), #6148 (YDB: the same predicate is moved from ON to WHERE), #6257 (open PR: keep outer-dependent LEFT JOIN predicates in ON when complex join conditions are used). YDB PR #6157 closed without merge.
- **CteUnion eager-load SQL shape** -- Eager loading through CteUnion emits a CTE without its join, is finalized too early, or throws on a computed member. Open: #5823 (CteUnion throws on a computed member in the parent projection), #6152 (Union-strategy eager load of a computed detail column throws ArgumentOutOfRangeException), #6292 (eager-loaded collection joined to an ordered CTE emits the CTE without the join), #6293 (WithUnionLoadStrategy over a join to an ordered CTE throws "Table not found"), #6294 (nested db.Select beside or inside an eager-loaded collection fails), #6281 (nested CteUnion marks the root query as finalized). Open PRs: #6282 (skip finalization on the query CteUnion builds) and #6285 (build the parent slots from what the parent row reads).
- **Unclustered open items** -- Below the theme threshold, listed for coverage: #5853 (Output clause emits duplicate columns on providers without DELETED/INSERTED tables), #6063 (YDB decimal with Precision but no Scale is written through a Decimal(P, 0) parameter), #6080 (a provider's refusal inside a projection filtered through AsSubQuery loses its reason), #6035 (ArgumentException "must be reducible node" for a correlated Select(anonymous).Distinct().Count(predicate) in a projection), #5787 (untranslatable aggregate selector inside a projection fails with "There is no method 'AggregateExecute'"; draft PR #5901 fixes it), #6246 (translator factory Expression and NotNullExpression build non-pure SQL expressions), #6255 (optimizer: nested conditional rewrite returns wrong rows when the branch values differ), #6243 (tests: cover operator precedence in generated SQL on every provider), #5921 (string.Format and interpolated string specifiers are dropped in generated SQL), #6102 (zero-column VALUES source renders an empty select list).
