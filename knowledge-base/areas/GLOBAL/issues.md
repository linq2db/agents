# GLOBAL -- GitHub themes

## Open themes

- **Mapping and inheritance** -- Inheritance filter review (#4305), abstract and intermediate inheritance reads (#3184, #4364, #1473), MultiInsert dropping InheritanceMapping values (#2988), composite property auto-mapping (#2873), composite objects in associations (#4139), fluent-API scope limits (#3041, #3136, #4073, #4893), attribute and fluent merging (#3119), contract-to-implementation mapping (#230). Derived-type writes through base-mapped tables are addressed by closed PR #5840. Dynamic columns on an entity without a `[DynamicColumnsStore]` member now throw instead of crashing or dropping values (merged PR #5946, see resolved).

- **Query cache and cached-query correctness** -- Recurring class of bugs where SQL or parameters built for one call are reused for another: cache growth and memory pressure (#3009, #5692, PR #5681, PR #5711, draft PR #5694 bounding MappingSchema attribute caching), extension results served from cache (#4266), and query builders that do not register SQL-shaping values with the cache (#6002). Open PR #6185 compares build-time values folded out of the SQL in the query cache. Newly reported in this class: compiled queries reuse their first build when a raw SQL format or closure argument changes (#6045), `[SqlQueryDependent]` values that are `Equals`-equal but render differently share one entry (#6059), and SQLite.MS grouped `MAX(CASE ... THEN string ...)` throws on the cached second execution (#6028). Open PR #6033 caches command text for constant TAKE/SKIP. Nested FromSql/Sql.Expr staleness (#6000, #5857) and the IN->EXISTS cached-query mutation are resolved, see below. Closed PRs #5723, #5791, #5801 and #5841 cover adjacent cache-mutation fixes.

- **SQL generation and optimization** -- Reserved-word lists for all providers, critical (#1126), NOT EXISTS / EXISTS join optimization (#2815), SQL Server ISNULL optimization (#3314, PR open), Skip/Take without OrderBy (#5342), grouping sets and rollup/cube (#4265), bitwise NOT (#4726), re-enabling an optimization disabled by #5074 (#5081), multiple result-set query builder (#5496), generic backlog (#4745). Recent open defects: set operation with a computed difference and declared duration (#5796), aggregate with an untranslatable selector inside a projection (#5787, fix PR #5901 draft), date/time literal losing sub-seconds against a coarser column (#5997, see the date and decimal theme below).
Further open SQL generation defects: an apply join whose source is a set operation is never decorrelated (#6034); a correlated `Select(...).Distinct().Count(...)` inside a projection fails with "must be reducible node" (#6035; open PR #6170 falls back to a sub-query for Distinct aggregates); `GroupBy(...).Select(g => aggregate).Contains(x)` puts the aggregate in WHERE on Access (#6047); an explicitly named DataParameter is renamed when a generated parameter claims its name first, so raw `@name` binds the wrong value (#6040); identifier quoting passes already-quoted names through verbatim and does not escape embedded quote characters on several providers, an injection vector when names are runtime strings (#6022); a nullable equality ORed with another condition is UNKNOWN when compared as a value on DB2 (#6065); a nullable inline-array `Contains` converted to a string returns NULL where C# returns "False" (#6066); a narrowing numeric conversion followed by a widening back is dropped before SQL is built (#6070); a DB2 recursive CTE anchor double-casts a DateTime literal (#6019, cosmetic).
Open PRs in the same area: #6158 (skip pulled-up joins in reference-correction walks, part of the #5738 audit), #6197 (DistinctBy row choice after Take/Skip, joins and GroupBy), #6257 (keep outer-dependent LEFT JOIN predicates in ON when complex join conditions are unsupported, YDB), and drafts #6282 and #6285 (CteUnion finalization and parent slots).

- **Query execution performance** -- Update performance on many tables (#4724), Collection.Contains optimization (#4600), client collection value inlining (#4584), SQL Server LoadWith optimization (#4588), query cache size limits (#3009), Futures support (#1404), task pooling (#3437), remoting serialization cost (#3800), bulk copy tuning (#2777). Constant TAKE/SKIP command-text caching: open PR #6033. Several reads in one round trip: draft PR #6111 (QueryBatch).

- **Associations and eager loading** -- Duplicate association queries (#3806), duplicate entity objects from incomplete association data (#4059), many-to-many associations (#2888), composite-object associations (#4139), LoadWith on fluent-configured children (#3041, #3136). Eager-loaded collections silently truncated on Sybase by a derived-table TOP (#5865; fix PR #5900 draft). Recent eager-load fixes are in closed PRs #5727, #5809, #5938 and #5939, and in merged PR #6220 (filtered ThenLoad on a SelectMany/join source, 2026-11-04). Eager-loaded projections over a missed LEFT JOIN row are open in #6046 (see the missed LEFT JOIN theme).

- **Remote query execution and LinqService** -- LinqService extensibility (#1949), batched multi-query execution over WCF (#1908), remoting performance (#3800), SQL divergence between direct and remote contexts (#5169). Remote SQL diverges from direct SQL because `SqlBinaryExpression` and `SqlUnaryExpression` lose their DbDataType on the LinqService path (#6055; fix PR #6057 draft). A visitor that rebuilds a typed binary expression also drops its DbDataType and a narrowing cast (#6056). Transports: SignalR remote redesign with cancellable streaming calls (PR #6014 open) and a gRPC shared channel per context (PR #6020 open).

- **Insert, output and bulk operations** -- Insert overloads that keep identity values (#5021), identity insert into IntoTempTable with IQueryable source (#3795), InsertWithResult multi result-sets (#2982), output on insert/update/delete (#3124, #3832), bulk copy returning inserted IDs (#2960), bulk insert ignore (#5124), ModificationHandler design (#2206), InsertOrReplace with custom key (#3597). Merge API: immutable models (#4237), custom setters for matched rows (#4357). INSERT ... RETURNING as a composable PostgreSQL source (#5717) is still open; its phase-1 PR #5982 was closed without merge (see resolved).

- **Transaction, retry and connection handling** -- Savepoints (#1935), automatic ambient-transaction enlistment (#2676), EF-style retry strategies (#3219), RetryPolicy with UPDATE statements (#4967), unexpected implicit transaction on SQL Server (#4053), async connection opening (#4930). Firebird: a cancelled async operation can leave a pooled connection half-written, and the next user of it hangs (#6012, open; the test-suite workaround PR #6013 is merged).

- **Type system and conversion** -- BigInteger SumAsync (#4040), .NET 7 numeric types (#3660), TimeSpan mapped to time (#4306), SAP HANA array types (#3302, PR open), DbType in parameter typing (#3787), JSON column types (#1661), union constant/parameter typing (#3360). Recent DateTime/DateTimeOffset work is in draft PRs #5892 and #5913; the sub-second and date-difference defects are #5997 and #5993. SQLite DateTimeOffset arithmetic that preserves the offset is open in PR #5931. On Microsoft.Data.Sqlite a DateTimeOffset column is read through GetDateTime, losing the offset, and MaxValue cannot be read east of UTC (#6031). Attribute-built SQL (`Sql.Ext`, `[Sql.Expression]`, `[Sql.Function]`) takes the mapping schema default type instead of the value type, which makes ClickHouse refuse an analytic MAX (#6044). The integer `Sql.Degrees` overloads keep the fraction where the engine DEGREES function returns a float (#6072). Date/time and decimal literal fidelity is grouped in its own theme below.

- **Expression translation and LINQ surface** -- Net 9/10 LINQ methods (#4412, PR open), C# with expressions (#3177), LastOrDefaultAsync on IOrderedQueryable (#4019), Order/OrderDescending on .NET 7 (#3694), .NET 6 future support (#2977). `Sql.Property` with a name taken from a lambda parameter fails with an undiagnosed exception (#5953). A provider refusal inside a projection filtered through `AsSubQuery()` loses its reason and reports only "could not be converted to SQL" (#6080). Nullable struct members through `.Value` and `.HasValue` do not translate when built in an inner projection (#6093, see the nullable theme). Open surface additions: SelectDynamic, a runtime column set in a projection (PR #6110; overlaps the PIVOT/UNPIVOT draft #5708), and comparisons over a projected enum cast with SetDefaultFromEnumType (draft PR #6277).

- **Schema and DDL** -- CreateTable gaps (#1789), default values on ColumnAttribute (#2277), unique index via fluent mapping (#4073), create and drop database (#5287), temp table indexes (#2827), SQL Server temp table collation (#4598).

- **Providers and new-provider requests** -- Sybase IQ (#2040), SAP Anywhere (#3398), MS SQL function calls without stored procedures (#1857), HANA procedure name escaping (#1740), per-provider identifier length limits (PR #5772), Access date-difference query complexity (#5993). Access: a correlated TOP 1 column subquery returns per-row wrong values (#6032), and the aggregate-in-WHERE case in #6047 above. SQLite.MS: grouped MAX(CASE) on cached execution (#6028) and DateTimeOffset reads (#6031). YDB: Math.Floor, Ceiling and Truncate over decimal lose precision through Double (#6041).

- **Configuration, infrastructure, AOT and tests** -- Secrets.json support (#3868), AOT code stripping (#4018), source generators (#2687), attribute-cache growth driving NETFX multi-config OOM (#5692; fix PR #5711 open, draft PR #5694).

- **.NET version and release-line work** -- .NET 11 support and drop of .NET 8/9 (draft PR #5942), C# 15 and runtime async on net11.0 (draft PR #5944), LibRed managed Access provider (draft PR #5956), LibRed extended SQL dialect (draft PR #5969), PIVOT/UNPIVOT (PR #5708, #1475).

- **netstandard2.0 build on modern runtimes** -- Modern runtimes that load linq2db's netstandard2.0 asset (through a netstandard2.0 library, or on a runtime whose TFM is dropped) miss translations and readers that exist only under net8+ gates. Open: `string.TrimStart()` / `TrimEnd()` no-arg and char overloads not translated (#6075; fix PR #6082 draft). C# 14 span `Contains` not recognised, reported as "could not be converted to SQL" on .NET 10 (#6067; fix PR #6074 draft). SAP HANA probes only `Sap.Data.Hana.Core.v2.1` and misses the .NET 8 client (#6076; fix PR #6083 draft). DuckDB `TIMETZ` to `TimeSpan` reader missing (#6084). MySQL `VECTOR` to `float[]` conversion missing (#6085). ClickHouse.Driver parameterised insert fails with unbound `p1` (#6086). The shared cause is that the conversions sit under `NET8_0_OR_GREATER` or `SUPPORTS_DATEONLY` gates that the ns2.0 asset does not see.

- **Missed LEFT JOIN rows and nullable values** -- With `PreferClientCalculation` off, a non-nullable column of an unmatched LEFT JOIN row is computed over SQL NULL in eager-load and CTE projections (#6046, open). With the option on, a math function over such a column throws "Nullable object must have a value" (#6087). Decimal division by such a column overflows on ClickHouse (#6089). A Sybase `DateTime` or `Sql.MakeDateTime` built from NULL parts raises instead of answering NULL (#6088).

- **Nullable structs and inner-projection values** -- Member reads and unions over a struct built in an inner projection and lifted to `Nullable<T>`, or typed as an interface or base class, still fail in the places below (fixed cases are in resolved). `.Value.<member>` and `.HasValue` do not translate (#6093). A union of a lifted struct with a `(T?)null` branch throws NullReferenceException on read (#6094). A correlated `Select(...).Distinct().Count(...)` inside a projection hits "must be reducible node" (#6035). An untranslatable aggregate inside a projection reports an internal AggregateExecute error (#5787; fix PR #5901 draft).

- **Date, time and decimal literal fidelity** -- Literals and casts are narrowed to, or typed as, a type that does not match the column or the value, and the answer changes without an error. Date/time literal narrowed to a coarser column type loses its sub-second part (#5997). MySQL `CAST` to a date/time type drops fractional seconds (#6049). A Sybase UNION of a `date` column with a `datetime` value truncates the datetime to midnight (#6050). SqlCe compares a decimal literal at the scale of the other operand, so `1.004` matches `1.00` (#6062). A YDB decimal mapped with Precision and no Scale is written through a `Decimal(P, 0)` parameter (#6063). A SQL Server datetime literal beside MAX or COALESCE of a datetime column is written as datetime2 and misses a stored value (#6078). SQLite and ClickHouse: a date column IN a list of datetime columns misses a match that `==` finds (#6081). Text-to-date/time casts are wrong on SQLite and Informix and return no rows on YDB (#6071). Inline IN list values are typed through SUM and type-changing casts (#6079). Fixes in review: DateTimeOffset difference measured on instants (PR #5892 draft) and time-zone answers (PR #5913 draft). The YDB ROUND emulation overflow and the ClickHouse date-operand coercion were fixed in merged PRs #5943 and #5959 (see resolved).

- **Scaffold, CLI and F# code generation** -- F# data-model generation for the CLI scaffolder (#1553, open since 2019; PR #5707 draft). A generated-code test harness that compiles and executes scaffold output for C# and F# (#6021; PR #6037 draft, stacked on #5707). A T4 template compilation error crashes `scaffold --customize` instead of being reported (PR #6036 draft). linq2db-cli credentials stores and a built-in local store (PR #5991 open), and impersonation scope limited to connection and execution (PR #5995 open).

- **Documentation** -- A linq2db Agent Skill shipped in the NuGet package with a `skill install` command and analyzer L2DB2001 pointing to it (PR #5376 open, updated 2026-11-10).

## Resolved themes

- **Query correctness regressions (2026-07 to 2026-11)** -- Nested UnionAll ordering (#5684, regression test PR #5685), parasite coalesce on aggregates in 6.3 (#5699), left-join predicate with nullable (#5781), window COUNT(*) with another window function (#5782), chained update/row lock hints (#5714), InheritanceMapping (#5729), OrderBy family (#5935), DistinctBy losing query state (PR #5732), entity filter dropping a null-check in set operations (#5792, PR #5831). Cached FromSql / FromSqlScalar / Sql.Expr nested in a query reused stale SQL (#6000, #5857), fixed by PR #6003 (merged 2026-10-16 per the earlier run; index updated 2026-10-23). IN->EXISTS conversion mutated the cached query (PR #6007, merged 2026-10-13). Raw SQL arguments the format never references are now sent as NULL, which fixes Sybase rejecting them (PR #6008, merged 2026-10-19). Oracle 11 query validator rejected IS NOT NULL on a column subquery over its own table (#6024, fixed by PR #6027 merged 2026-10-12). Concat/Union over EF value-converter columns threw "operands do not match" (#5976, closed 2026-10-09; no linked PR in the index). Union over columns sharing one value converter class threw ArgumentException (#6052, fixed in 6.5.1 by #5978; regression test PR #6060 merged 2026-10-16). Query cache crash on x86 hosts that unmask FPU exceptions (#6042, fixed by PR #6053 merged 2026-10-15).
  Also merged 2026-10-22 to 2026-11-10: NULL rows kept when negating a nullable comparison read as a boolean (#6121; the same-titled #6119 was closed unmerged), projected aggregates after a method-call projection (#6211), a set-operation branch cast to object keeps its projected members (#5919), a client-only array Length bound as a parameter (#6103), window values read through GroupJoin computed in their own subquery (#6190), a predicate used as a value reduced after its slot decides (#6201, child of #5673), a concat whose literals need no folding kept as built (#6136), and joins inside APPLY subqueries kept instead of lifted out (#6229). Single-traversal null folding (#5909) also merged.

- **Compilation and build performance** -- Query compilation regression since 6.0 (#5719, PR #5737 TPH fix), compiled query with LoadWith (#5842, PR #5844), LoadWith forcing thread-pool use (#5805, PR #5809).

- **Type system and mapping** -- DateTimeOffset.DateTime sorting (#5435), NodaTime Instant? parameter inference (#5549), char null valueConverter (#5654), F# option types (#195), arithmetic between value-converted columns (#5798), UpCastDbDataTypeToFit overwriting Length (#5826). Operators between two value-converted columns stored on different terms are now refused instead of adding the stored numbers (#5902, merged 2026-10-23). x86 FPU-trap JIT faults in provider code: closed #6051, fixed by PR #6058 (merged 2026-10-19).

- **Missed LEFT JOIN projection values (2026-09 to 2026-10)** -- The non-nullable member of a missed LEFT JOIN row read as default(T) but was NULL inside SQL calculations (#5932, #5923), fixed by PR #5983 (merged 2026-10-21), which makes SQL read such a column as COALESCE(col, default(T)) in projection calculations. The eager-load and CTE shapes remain open in #6046.

- **Nullable structs and inner-projection fixes (2026-10 to 2026-11)** -- A struct built in an inner projection and lifted to `Nullable<T>` or upcast fails on member reads with "Property is not defined for type Nullable<T>" (#6090, fixed by merged PR #6091, which changes SequenceHelper.CorrectTrackingPath). A struct referenced twice in an outer projection fails with "Coalesce used with type that cannot be null" (#6068, fixed by merged PR #6069, which memoizes a repeated constructor in FinalizeExpressionVisitor).

- **Interface and member translation** -- "Property X is not defined for interface type Y" on a Select-then-Where over an interface cast (#4199). Fixed in 6.0.0-preview.1 by #3401; the repro test added in #4676 never reproduced the issue, and the rewritten test with the gate removed is PR #6097 (merged 2026-10-21). Interface-typed cast with association properties breaking SQL generation (#4773, closed 2026-10-22). Associations reached through an interface that a base class does not implement (#6109, merged 2026-10-23).

- **Build and infrastructure** -- Linux DB2/Informix libdb2.so loading (#5538), NuGet pack HintPath resolution, analyzer rules deferred from 6.3.0 (#5532), sqlserver2016 script rename (#5990), analyzers shipped via linq2db.Analyzers (PR #5720). Recent CI and infrastructure merges: NuGet audit suppression and pins (PR #6043), SignalR client floor raised past the GHSA-334f-vvp4-7g6p range (PR #6095), LINQPad pack double-build race (PR #6030), Access x86 leg split per provider (PR #6005), macOS leg for CLI tests (PR #6017), baselines push back-off on server errors (PR #6004), Docker Hub login on Azure legs (PR #6011), MySQL CreateDatabase self-heal (PR #6054), test-only Firebird pool workaround (PR #6013), DB2 pool purge at assembly teardown (PR #6073), remote test clients no longer leak connections (PR #6010), passing [ActiveIssue] gates removed (PR #6015), Sybase UnusedSource_Query excluded instead of gated (PR #6029), filtered heartbeat total (#5964, fixed by PR #6098 merged 2026-10-21).
  Also resolved: direct-vs-remote baseline comparison on every run with declarative `[NoBaselines]` and `ActiveIssue(BaselinesMismatch)` (PR #6061, merged 2026-10-28), the Examples solution building in Release (#5945, closed 2026-10-24), WASM runtime testing (#5159, closed 2026-10-27), case-sensitive SQL Server schema testing (#4658, closed 2026-10-27), and reflection BindingFlags review (#4314, closed 2026-11-04).
